## Suggested study order

1. **[principles.md](principles.md)** — SOLID comes up in almost every backend interview.
2. **[agile.md](agile.md)** — Scrum ceremonies are the easiest guaranteed points.
3. **[architecture.md](architecture.md)** — monolith vs microservices trade-offs.
4. **[system_design.md](system_design.md)** — the differentiator for mid/senior roles.
5. **[testing.md](testing.md)** + **[process.md](process.md)** — proves team experience.
6. **[interview.md](interview.md)** — STAR stories; write them out, don't improvise.
